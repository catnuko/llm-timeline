# Code of Conduct

## Our pledge

We want participation in this project to be harassment-free for everyone,
regardless of age, body size, visible or invisible disability, ethnicity,
sex characteristics, gender identity and expression, level of experience,
education, socio-economic status, nationality, personal appearance, race,
religion, or sexual identity and orientation.

## Expected behaviour

- Be direct about the work, kind about the person.
- Critique ideas and code, not contributors.
- Accept that maintainers make the final call on scope.

## Unacceptable behaviour

- Harassment, insults, discriminatory jokes, or sexual attention of any kind.
- Publishing others' private information without permission.
- Sustained disruption of issues, pull requests, or discussions.

## Enforcement

Report problems to the maintainer via a GitHub issue or a private message
to [@catnuko](https://github.com/catnuko). Maintainers may remove comments,
close pull requests, or block accounts that violate this policy.
